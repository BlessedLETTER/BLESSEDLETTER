## v1.9.4 — 2026-10-18

**新功能：便笺墙「复制 / 粘贴」；「关于」显示版本号、作者与项目主页**

### 1. 复制 / 粘贴便笺

- 原来的「复制一份」拆成两步：**复制便笺**把选中便笺存进程序内剪贴板，**粘贴便笺**在当前页新建一张；
  **先点「本页已满 · 新开一页」再粘贴，新便笺就落在新页上**。
- 入口：工具栏「复制 / 粘贴」、编辑菜单、便笺右键菜单、快捷键 `Ctrl+C` / `Ctrl+V`
  （`Ctrl+D` 保留为“复制”的旧别名）。顺带修好了原来工具栏「复制」和编辑菜单「复制一份」点了没反应的问题。
- 粘贴是整份复制：标题、正文/富文本、附件路径、照片设置、提醒设置都照搬，分配新 id；
  **标题保持原样**（不自动加「（副本）」），需要区分时 `F2` 改名。
- 空剪贴板时「粘贴」按钮和菜单项是灰的；剪贴板只在本次运行内有效，不占用系统剪贴板。
- 搜索框里的 `Ctrl+C` / `Ctrl+V` 仍是复制/粘贴文字，不会被日程命令截走。
- **顺带修好的页相关老问题**：
  - 换页/新开页时清掉旧页的选中——以前视图一重建就会把选中项所在页“恢复”回来，把新开的页又翻回旧页；
  - 粘贴后立刻保存新便笺的页归属（否则重启后它会回到第 1 页）；
  - 启动时恢复上次看的页；历史便笺在墙信息里没有页记录时默认第 1 页，而不是被错误地记到当前页。

### 2. 关于

- 「帮助 → 关于」（`F1`）改为带超链接的对话框：显示 **当前版本号 `v1.9.4`**、**作者「祝筱笺」**、
  项目主页 `https://github.com/BlessedLETTER/BLESSEDLETTER/tree/BlessedMemo`
  （蓝色超链接，点击或「打开项目主页」按钮都会用浏览器打开）。
- 版本/作者/链接集中定义在 `zsched.h` 的 `APP_VERSION` / `APP_AUTHOR` / `APP_URL`，以后升版本只改一处。

数据格式不变（`imgb0=`、页记录 `page=` 都照旧），不需要迁移。

## v1.9.3 — 2026-10-18（紧急修复）

**修复：便笺用滚轮翻到最底、或把照片放大之后，正文被挤掉消失**

1. **正文被“滚了两次”**（主因）：布局里已经把正文起点减过一次滚动量（`textTop -= scroll`），
   绘制时又减了一次（`r3.top = textTop - scroll`）。照片只上移一份、正文上移两份，
   滚得越多正文越跑到自己的裁剪框上面去，**滚到最底时整段正文都在裁剪框外 → 字消失**。
   现在**只减一次**，正文和照片一起滚。
2. **裁剪框跟着正文起点跑**：以前裁剪上边用的是“已滚动的正文起点”，照片把正文顶到便笺下方时，
   这个起点本身就在可视区外，滚轮永远滚不进来。现在裁剪固定在**内容视口**（日期行顶/正文起点）到底边，
   滚到最底时最后一行正好贴在内容区底边；往上滚能完整回到照片与第一行。
3. **照片手动放大后不再挤掉正文**：以前只要拖过照片四角（`imgB[2] >= 60`），照片区就吃满整个正文区，
   正文被顶出可视区。现在**只要有正文就永远留出一行**（独立便笺 `lhText + 间距`，便笺墙卡片 `lhSmall + 4u + 间距`），
   照片再大也压不掉；**正文开头的空行也计入预留**——像「CMC数竞初赛」这种 `\n\n高等代数…`，
   留的是那一行实际文字而不是空行。`IMG_MIN_H` 最小高度只在“放得下这一行”时生效；拖照片本体的夹紧也同步，
   照片最多拖到正文最后一行上方。
4. **滚动内容统一裁在视口里**：日期、倒计时、照片、正文一起裁（上边为内容视口顶），
   往上滚时不会压住便笺标题；滚动条、悬停按钮、附件行保持固定。
5. **便笺墙卡片同一口径**：卡片上的正文也修掉“双倍滚动”，照片放大同样保留一行正文。

数据格式不变（`imgb0=` 千分比照旧），不需要迁移。

## v1.9.2 — 2026-10-18（加急修复）

**修复：独立便笺上的照片「鼠标一离开就消失」，以及「指针一放上去就进入编辑状态」**

1. **照片不再随指针离开而消失**（本次加急的主 bug）：
   画「浮于文字上方」那一层照片（以及便笺墙卡片上的照片）时，以前还额外要求“鼠标正停在照片上”（`imgHotIdx >= 0`）；
   v1.9.1 为了在指针离开时收起手柄，把 `imgHotIdx` 清成了 -1，结果照片也跟着整张不画了。
   现在**照片无条件绘制**——指针在不在、选没选中，照片都一直在。
2. **悬停不再进入照片编辑**：虚线框与四个角手柄以前是跟着“悬停”画的，指针一扫过照片就出现，像是自动进了编辑。
   现在**只有单击选中后才画手柄**；悬停只改光标（本体 = 移动，角上 = 斜向缩放），不重绘、不出手柄。
3. **右键退出照片编辑模式**：选中照片后**按右键**即取消选中（手柄与虚线框消失，照片保留），同时照旧弹出便笺右键菜单（`Esc` 关闭）；
   **单击便笺其他位置**也退出；双击照片仍是打开这条例程的编辑窗。
4. **便笺墙卡片同一口径**：清单视图的便笺卡片上同样——悬停只变光标、单击选中才出手柄、右键/点别处退出。
5. **顺带修好“照片框被最小尺寸撑开”**：布局末尾还有一条“框不小于最小宽/高”的钳制，
   它会把已经按比例缩好的照片框重新撑大，撑出来的部分在 contain 绘制下就是左右/上下的无效空白（选中框也比照片大一圈）。
   现在**框永远贴住照片本身**（独立便笺与便笺墙都改了）；最小尺寸只在手动拖角时防“缩成一条线”。

数据格式不变（照片位置/大小仍是 `imgb0=` 千分比），升级不需要迁移。

## v1.9.1 — 2026-10-17（紧急修复）

**修复：便笺本界面（清单视图的便笺墙卡片）上的照片没跟着 v1.9 改——同样的三个问题一并修好**

1. **照片按自身比例完整显示**：卡片上的照片以前还是“铺满裁切 + 八个手柄”，扁卡片里竖图被上下切掉、宽卡片里横图被左右切掉。
   现在和独立便笺一致：按照片自己的宽高比放（contain），整张永远看得全、不变形；
   框与照片严丝合缝，框里不再出现“预留却空着”的无效空白。
2. **四个顶角两维同比例缩放**：卡片上悬停照片会出现四个角的小方块，拖任意一角 = 宽高一起按比例变；
   鼠标在角上是斜向缩放光标、在照片本体是移动光标（和拖动便笺位置彻底分开）。

3. **没有正文不留空白 / 调过大小用满卡片**：卡片没有正文时不再给正文预留高度；
   手动调过照片大小后，照片区直接用满卡片正文区（扁卡片里也能把竖图放到卡片高度）。
4. **Ctrl+滚轮不再缩放照片**（和独立便笺一致）；滚轮用来滚动卡片内容。
5. **拖动只改位置**：照片本体拖动时尺寸完全不变（顺带修了“拖动时夹紧逻辑会改高度导致照片变形”的老问题）。

（底层与 v1.9 共用：`img_draw_fit()` 等比完整显示、框按照片比例生成、最小尺寸只防“缩成一条线”。）

## v1.9 — 2026-10-17

**修复：独立便笺的照片交互——四角双向缩放、单击选中拖动 / 双击进编辑、照片再也不被便笺形状裁掉**

### 1. 照片按自己的比例「完整显示」（contain），不再被便笺形状裁剪

- 以前照片是按便笺给的框**铺满裁切**（cover）：扁便笺里竖图被上下切掉、窄高便笺里横图被左右切掉，
  框里还会留一块“给正文预留却空着”的位置，看起来像无效空白。
- 现在照片框**跟着照片自己的宽高比走**：整张照片永远看得全、不变形，
  框内也不会出现无效空白（框和照片严丝合缝）。
- **便笺没有正文时不再给正文留高度**（以前会空出一行），照片可以更充分地占满便笺。
- **手动调过照片大小时**（拖四角 / 右键「照片 → 大小」选过比例），照片区直接用满整个正文区——
  扁便笺里也能把竖图放大到便笺高度，不会因为“给正文留的那一条”而长不高。

### 2. 四个顶角：两个维度同时缩放

- 鼠标移到照片上会出现**四个角的小方块**（悬停或刚操作过时），拖任意一个角：
  **宽高一起按比例变化**（两个维度同时缩放，照片始终不变形、整张可见）。
- 只认**四个顶角**：边的中段不再作为缩放手柄，避免和“拖动照片位置”混淆。
- 光标区分明确：角上是斜向缩放光标（↘ / ↙），照片本体是“移动”光标，空白处是便笺本身的拖动光标。
- 角的缩放范围按“照片可用区域”算：最大可以顶到便笺正文区的上下边；
  手动调过大小后，照片就是“用户尺寸”，正文自动让位（需要正文时再缩小照片或双击编辑）。

### 3. 单击选中拖动 / 双击进编辑

- **单击照片**：选中它（出现虚线框 + 四角手柄），按住拖动就是**移动位置**——尺寸完全不变。
- **双击照片**：直接打开这条例程的编辑窗（和双击便笺空白处一致）。
- 状态栏会给操作提示（选中 / 已移动 / 已调整大小）。
- 便笺自己右下角的缩放手柄仍然可用（照片四角手柄优先，避免抢位置）。

- 拷贝前会先把内存里的数据与便笺状态写盘，保证拷出来的是“现在这一份”；复制完自动打开这个文件夹。
- 同一秒连点两次不会互相覆盖：第二个文件夹自动变成 `…_2`、`…_3`。
- `迁移说明.txt` 里写清了怎么用：把文件夹拷到新电脑、把 `笺.exe` 放进去直接运行；
  或者在新电脑上「文件 → 数据保存位置 → 选择数据文件夹…」选中它。

### 2. 修复：数据拷贝里 `zsched_history` 目录一直是空的

- 「备份当前数据到文件夹…」「迁移」「切换数据目录时顺带迁移」都走 `app_data_copy_to()`；
  它的历史目录循环把源路径拼成了“数据目录 + 文件名”（漏了 `zsched_history\` 这一层），
  所以**历史版本从来没有被复制过**（目标里的 `zsched_history` 是个空目录）。
- 现在改成用专门的历史目录变量拼路径，实测拷贝里三个历史快照都在。

## v1.7 — 2026-10-17

**修复：课表接力改为「下课后 5 秒」换窗；新增：只勾提示音时的「停止铃声」小窗**

### 1. 课表便笺：下课 5 秒后才把整个窗口换成下一节

- 以前：一到下课时间就关掉这一节的便笺；
  - 连堂（下一节紧接着上）会立刻在原位置开出下一节 ✓；
  - **有课间空档时，窗口会先消失，一直等到下一节开始才重新出现** ✗。
- 现在按需求改成：**下课那一刻先不关窗**，等 **原课程结束时间 + 5 秒**，再把**同一个位置上的窗口整个换成下一节**：
  - 连堂：5 秒后换成正在上的下一节；
  - 有课间：5 秒后就换成下一节的便笺（显示「距上课 mm:ss」，不用等到上课）；
  - 今天已经没有下一节：5 秒后关窗，不留空窗。
  - 这 5 秒里窗口上显示的是「本节已下课」（原来的文案），不会再出现两节便笺抢同一个位置。
- 实现：`tt_tick()` 拆成两段 —— ①每节课只负责“该开就开 / 下课记下 `handoverAt = en + 5`”；
  ②到期交接：记忆位置 → 关旧窗 → 开下一节（`sched_class_now()` 优先，否则 `sched_class_next()` 取今天之后最近的一节）。
  交接待办期间（最多 5 秒）不会让别的课提前抢开，避免两窗口重叠。

### 2. 只勾「提示音」时也有手动关闭按钮

- 以前：提醒只勾了「提示音」时没有弹窗可点，自选铃声（mp3/flac）一放就要等到它自己播完——没法手动停。
- 现在：这类提醒响铃时会弹出一个**小窗**（便笺纸色，右下角）：
  `铃声提醒 · 这是铃声` + 日程标题 + 一个真正的 **「停止铃声」按钮**（点按钮或点窗口都立即停铃）；
  **声音播完后小窗会自己关掉**（按 Media Foundation 读到的时长判断）。
- 勾了「便笺弹窗」的提醒**不会**再弹这个小窗（弹窗本身点了就停）；小窗出现时如果又来了带弹窗的提醒，
  小窗会先收掉，交给大弹窗处理。

## v1.6 — 2026-10-17

**新增：铃声内置播放 mp3/flac；便笺容量上限移除 + 便笺墙翻页；表格关键词搜索；后台运行（托盘，不占任务栏）**

### 1. 铃声支持 mp3 / flac（程序内直接播放，不再拉起外部播放器）

- 新模块 **`sound.c`**：`Media Foundation`（SourceResolver + 音频渲染拓扑）直接播 ——
  wav / mp3 / flac / m4a / wma / aac 都能响（Windows 10+ 自带 FLAC 解码器）；
  MF 不可用时退回 **MCI**（老系统 wav/mp3），再不行才交给系统默认程序（v1.5 的老办法）。
- 「铃声…」菜单：`试听（在本程序里播放）` / **`停止铃声`** / `用默认播放器打开` / `清除自选文件`；
  提醒到点时同样是**程序内播放**（点了提醒窗、或 30 秒自动关，铃声就停）。
- 实测：mp3、flac 到点都会响，**不再出现外部播放器进程**；弹窗照旧写 `铃声：xxx（这是铃声）`。

### 2. 便笺容量上限移除 + 便笺墙「翻页」

- **便笺窗口不再有 64 个的上限**（`g_notes` 改动态数组），**启动也不再只恢复 24 张**——
  实测开满 80 张便笺、退出后重启，80 张全部恢复。「为全部待办开便笺」也不再写死 24 条。
- 便笺墙有了**页码栏**（页面底部居中）：`‹ 第 1 / 3 页 ›` + `＋ 新一页`；
  这一页的便笺装不下时按钮会变成**朱红实心的「本页已满 · 新开一页」**，
  点它（或 `PgUp` / `PgDn`、视图菜单「上一页 / 下一页 / 新开一页」）就能翻页 / 新建。
- **一条便笺属于哪一页**：在某一页新建的便笺就记在这一页（`zsched_board.txt` 里存 `page=`）；
  右键便笺多出「这张便笺在第 N 页 / 移到上一页 / 移到下一页」，可以随手挪页；当前页数与总页数存 `viewpage=` / `pages=`，
  重启后还停在上次那一页，空页也不会丢。
- 「便笺都收起来了」的提示改为按**当前页**判断（以前会拿全书的张数比）。

### 3. 表格视图关键词搜索

- 表格视图顶部右侧多了一个**搜索框**（带提示文字「搜索：标题 / 正文 / 链接（Esc 清空）」）。
- **边打边筛**：输入关键词立即过滤表格（不区分大小写的子串，标题 / 正文 / 链接都查），
  状态栏显示「搜索「xxx」：N 条」；`Esc` 清空，`Ctrl+F` 随时跳回搜索框。
- 只影响表格视图；切回清单 / 周表不受影响，切回表格时关键词仍然生效。

### 4. 后台运行（托盘，不占任务栏）

**新增：提醒铃声可选“自选声音文件”（提醒时自动打开所选文件，弹窗标注「这是铃声」）；CSV 课表导入（正则识别 → 逐行生成课表便笺）**

### 1. 铃声选择（编辑窗「提醒」那一行 →「铃声…」）

- **两种来源随便选**：`系统提示音（Windows 默认）` / `自选声音文件`（二选一，勾选态显示当前是哪种），

  实测 `.wav` 会拉起系统播放器；文件被删或路径失效时**自动退回系统提示音**（不会变成没声音）。
- **弹窗会写明“这是铃声”**：便笺纸提醒窗多一行 `铃声：xxx.mp3（这是铃声）`（朱印红），窗口相应加高；

- 数据文件新增两行 `sndmode=0/1`、`sndfile=<路径>`：老数据没有这两行 → 仍是系统提示音（行为完全不变），
  旧版本读到这两行会忽略；路径按既有规则转义（`\` 写成 `\\`），随「保存/存档/历史版本」一起走。

### 2. CSV 课表导入（文件 → 导入 CSV 课表…）

- **两种常见格式都能认**：
  - **表格型**：一行一节课，表头里有「课程名称 / 上课时间 / 星期 / 节次 / 日期」等列（列名不认识时按内容推断）；
  - **网格型**：学期课表那种「行 = 节次、列 = 星期」，格子里填课程名（可带教师/教室；多行或空行分隔的多门课也认）。
- **正则匹配识别**：本机工具链没有 `<regex.h>`，所以自带一个极简正则引擎（放在 `csvimport.c` 里）——
  支持 `.` `[a-z]` `[^…]` `\d \D \w \W \s \S`、`* + ? {m,n}` 贪婪量词、`( )` 捕获、`(?: )` 非捕获、`|` 分支、`^ $` 锚点与忽略大小写；
  匹配器用「续接（continuation）」实现，组 / 分支 / 量词都能正确回退（`(a|ab)c` 这种也能命中）。
  用它识别：星期（`周一 / 星期三 / 礼拜日 / 周3 / mon…`）、时刻（`8:00 / 8.00 / 8点30`，全角数字先转半角）、
  节次（`第3-4节 / 1、2节`）、日期（`2026-11-20`）以及表头关键词。
- **只取便笺支持的信息**：名称 → 标题；时间 → 开始/结束 + 重复（有星期几就按每周 + 星期掩码）；
  **其余列一律按「列名：值」写进正文**（教师 / 教室 / 学分 / 周次 / 备注…）；时间是从「节次」推出来的会在正文里注明
  （内置作息表：第 1 节 08:00、第 2 节 08:55 …每节 45 分钟）；序号列（纯数字）自动丢掉。
- **识别结果先给确认框**：显示「格式 / 表头行 / 分隔符 / 名称列 / 时间列 / 其余 N 列写入正文」+ 逐条预览
  （`1. 高等数学 周一 8:00-9:40 · 正文 3 行`），两个入口：「导入并打开便笺」/「仅导入到清单」。
- **生成的是课表便笺**：每条课程 `timetable=1`（到点自动开关便笺）、倒计时默认到分、纸色按调色板轮转；
  「导入并打开便笺」会顺手把视图切到清单并把便笺贴出来（一次最多 16 张）。
  同名 + 同星期 + 同时间的行**自动跳过**（重复导入同一份课表不会翻倍），状态栏汇报“导入 N 节 / 跳过重复 M 条”。
- **编码与格式都做了兜底**：UTF-8（带/不带 BOM）/ UTF-16LE（记事本的“Unicode”）/ GBK 三种编码自动识别；
  分隔符在 `,` `;` `Tab` `|` 里自动挑；引号包裹、`""` 转义、**引号里的换行**（Excel 导出的多行单元格）都能正确读。

验证：见 `progress.md` §7 —— 正则/识别用离线探针（6 组样例 CSV：表头型、星期+节次、网格、GBK、无表头、带日期），
铃声与导入都做了真机集成测试（提醒到点真的打开了所选文件、弹窗出现「（这是铃声）」；导入对话框 → 生成便笺并落盘）。

## v1.3.2 — 2026-10-16

**修复：收起便笺的残影、课表便笺不显示倒计时、提醒次数改了不生效**

1. **清单里便笺多时，收起一张会留下残影**：画便笺时用的是“这一页要画的顺序表” `z[]`，
   但循环上限写的是“便笺总数”，而收起便笺后 `z[]` 里有效项变少——多出来的那几趟读到的是**上一轮的残留下标**，
   于是把已经收起的便笺按旧位置又画了一遍（看起来就是残影）。现在记录了有效项数 `zCount`，
   循环只走有效项，并在画之前再判一次“是否已收起”，`st_rect()` 对收起的便笺直接返回空矩形。
2. **课表便笺（如「概论」）不显示倒计时**：以前只要“今天这节课不在进行中”，倒计时框就写死「本节已下课」或
   「课表 · 今天没这节」——**没有倒计时**。现在这两种情况都回退到普通倒计时：今天这节已上完 →「下节课 …」，
   今天没有这节（例如每周只有周日）→「还有 …」；只有真的没有后续安排时才显示「课表 · 暂无后续」。
   便笺墙上的课表便笺同样处理。
3. **提醒的“提前 / 重复间隔 / 共 N 次”改完确定后不生效**：编辑窗读这三个数字框时误用了 `ctl_text()`——
   它其实是“**写**控件”的（内部是 `SetWindowText`），于是相当于拿未初始化的缓冲区覆盖控件、再解析这段缓冲，
   用户输入的值永远被丢掉。改用 `ctl_int()` 读取。另外把“方式/提前/间隔/次数”也纳入提醒状态，
   任意一项改变都会重新计时（以前改完设置要等下一个周期才可能生效，甚至永远不会再提醒）。

验证：12 张便笺收起前两张后无残影（截图）；课表便笺的两种情况分别显示「下节课 20:59:54」「还有 00:59:55」（截图）；
用真实鼠标键盘把“提前=5、共 3 次”写入并确认落盘；把“提前”从 0 改成 1 后提醒在 start-60s（+30 秒）就弹出，
证明改设置会重新计时。
