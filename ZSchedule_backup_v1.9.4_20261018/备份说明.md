## 一、这是什么版本

**v1.9.4**：便笺墙的「复制」细化为**复制 / 粘贴**（可以把便笺复制到新开的一页），
「关于」里显示版本号、作者与项目主页（上一版备份在 `..\ZSchedule_backup_v1.9.3_20261018\`）。

1. **复制 / 粘贴便笺**
   - **复制便笺**（`Ctrl+C` / 工具栏「复制」 / 编辑菜单 / 右键菜单）：把选中的便笺整份存进程序内剪贴板。
   - **粘贴便笺**（`Ctrl+V` / 工具栏「粘贴」）：在**当前页**新建一张一模一样的便笺（新 id）。
     先点页面底部「本页已满 · 新开一页」，再粘贴，新便笺就落在**新页**上。
   - 标题、正文/富文本、附件路径、照片设置、提醒设置都照搬；标题保持原样，需要区分时 `F2` 改名。
   - 空剪贴板时「粘贴」按钮/菜单是灰的；剪贴板只在本次运行内有效，不占系统剪贴板。
   - 搜索框里的 `Ctrl+C/Ctrl+V` 仍然是复制/粘贴文字，不会被日程命令截走。
2. **关于**
   - 「帮助 → 关于」（`F1`）显示当前版本 **v1.9.4**、作者 **祝筱笺**、
     项目主页 `https://github.com/BlessedLETTER/BLESSEDLETTER/tree/BlessedMemo`（蓝色超链接，可点击；
     下方也有「打开项目主页」按钮）。
3. **顺带修好的页问题**：换页/新开页时清掉旧页选中（视图重建不再把页跳回去）；
   粘贴后立即保存新便笺的页归属；启动时恢复上次看的页，历史便笺默认第 1 页。

## 二、数据兼容性

- 主数据仍是 `ZScheduleData/4`；照片/页记录（`imgb0=`、`page=`）格式不变，**不需要迁移**。
- **数据文件不在这个备份里**：默认在 exe 同目录，或在 `HKCU\Software\Jian\DataDir` 指定的目录。

## 三、怎么运行

先按下一节编译，再双击 **`build\bin\Release\笺.exe`**（绿色免安装）。首次运行会生成 5 条演示日程；
要接上自己的数据，用「文件 → 数据保存位置 → 选择数据文件夹…」指到原来的目录即可。

## 四、怎么自己编译

需要 CMake 3.21+ 和 Windows C 工具链。使用 MinGW-w64 / w64devkit 时，
先将工具链的 `bin` 加入 `PATH`，然后在本目录执行：

```bat
cd /d <本目录>
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel
```

产物为 `build\bin\Release\笺.exe`。MSVC、Debug 和辅助工具的构建命令见
[README 的编译说明](README.md#二编译)。
**编译前先关掉正在运行的 `笺.exe`**。
