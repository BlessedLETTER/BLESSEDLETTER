# ZSchedule · 桌面日程管家

一款用 **纯 C 语言 + Win32 API** 编写的 Windows 桌面日程软件，单文件 exe、绿色免安装。
除系统自带的 `gdiplus.dll` / `comctl32.dll` / `msftedit.dll` 外无任何依赖。

界面走**纸质书质感**：主窗口本身就是一本**笔记本**——深色封皮、左侧螺旋装订、暖米纸页与红色页边线；
每条日程是一张**贴在页面上的便笺**（胶带 + 折角 + 柔和投影），可以随手挪位置、钉住、改大小。

---

## 一、功能一览

| 需求 | 实现情况 |
| --- | --- |
| 清单化呈现 | **清单视图 = 笔记本上的便笺墙**：便笺含类别色点、标题、日期与重复、倒计时框、正文摘要、附件角标；支持**自由拖动 / 固定 / 缩放**，内容（字号、行距、内边距）随便笺尺寸自动适配，见下节 |
| 表格化呈现 | **表格视图**：8 列网格（标题 / 开始 / 结束 / 重复 / 下次发生 / 倒计时 / 附件 / 摘要），首列带完成勾选框，点列头切换排序；纪念日带 ◇ 前缀 |
| 按周小时段表格 | **周表格视图**：7 列（周一~周日）× 24 行（每小时一格，半小时加一条浅线）网格，重复日程自动展开到当周每一天；日程按**真实时长**画占用条——09:30–10:00 就只占 09:30~10:00 那一小段，绝不撑满整格；时间重叠的日程自动分泳道并排；当天列高亮、红线标出当前时刻；双击空白格在该时段新建、双击日程块进编辑 |
| **周表缩放（可视化）** | 表头右侧一排控件：`−`、**五格阶梯档位条**（填色格数 = 当前档位）、`+`、`适`。5 档（60% / 80% / 100% / 130% / 170%）另有 `Ctrl+滚轮` / `+` `-` 键 / 视图菜单；缩放时保持视口中心时刻不变 |
| **周表自适应** | 点 `适` 把 24 小时压进当前可视高度（档位条变灰、标签显示「自适应」），整周不用滚动；窗口大小变了再点一次即可 |
| **周切换 + 按日期跳转** | 表头 `◀` / `本周` / `▶` 翻周；右侧日期选择器点开日历，点任意一天即跳到那一周（日历弹出层也已调成纸质配色） |
| **无时间待办** | 编辑窗勾选「无时间待办（不设时间，只记标题与内容）」：便笺上不显示日期与倒计时，改画一个**勾选框 + 「待办（无时间）」**；不参与倒计时、不上周表，排序统一排在最后；再点一次即恢复成普通日程（时间设置不会丢） |
| **照片版式（参考 Word）** | 一张便笺上的照片可以选三种版式：**浮动**（自由拖到任意位置、**四个角双向缩放**）、**随文**（排在正文里，文字自然排在照片下面）、**文末**（正文在前，照片排在正文之后，往下滚就能看到）；还能选**浮于文字上方**或**衬于文字下方**（层次只影响照片与文字的叠放顺序）。右键便笺的「照片（可拖动、可缩放）」子菜单里切换 |
| **多张照片各自独立** | 一张日程插了多张图片时，便笺上会**逐张**显示，每张都有自己的位置与尺寸：单击哪张就选中哪张（红色虚线框 + 四个角手柄），拖动、缩放都只作用于选中的那张；鼠标只是经过照片时**不会进入编辑状态**（只变光标）|
| **便笺直接显示图片** | 带图片附件的日程可以让便笺**直接把照片贴出来**（不再只显示「附件 N」）。照片是便笺上一个**独立的小框**：**单击选中**后才能拖动位置、拖四个角两维同比例缩放（悬停只把光标变成移动/斜向缩放，**不会自动出手柄**）；**单击便笺别处或按右键退出照片编辑**（右键同时弹出便笺菜单，`Esc` 关掉即可）。也可以右键「照片（可拖动、可缩放）」选 40/55/75/100% 与「位置与大小复位」|
| **照片永远完整显示** | **独立便笺与便笺墙卡片一致**：照片按**自己的比例**放（contain），整张永远看得全、不裁切、不变形，框与照片严丝合缝，框里没有“预留却空着”的无效空白；没有正文时不再给正文留高度，照片可以占满便笺/卡片；手动调过大小后照片区直接用满正文区（扁便笺也能把竖图放到便笺高度）。**单击照片选中并可拖动位置、拖四个角两维同比例缩放、双击直接进编辑窗**；光标会区分「斜向缩放」与「移动」。**鼠标移开照片或便笺时照片不会消失**（v1.9.2 修复）|
| **便笺内容超长可滚轮翻看** | 正文比便笺放得下的部分更长时（内容太长、或把便笺压得太小），便笺右侧会出现一条细滚动条；鼠标停在这张便笺上滚滚轮就**在便笺里翻看剩余内容**（**滚到最底时最后一行贴在底边、正文完整可见**），状态栏会显示「滚轮继续看 位置/总长」。正文按内容区宽度自动折行，滚动时标题固定、照片/日期/倒计时/正文一起滚（不会压住标题）|
| **收起便笺** | 笔记本页面上可以把便笺**收起来**：右键「收起这张便笺」或按 `H`；视图菜单里有「显示所有便笺（摆回收起的）」与「把便笺全部收起来 / 显示全部便笺」。收起的便笺不占位也不挡视线，状态记在 `zsched_board.txt` 里，状态栏会提示收起了几张 |
| **提醒** | 每条日程可独立设置提醒：**便笺弹窗 / 通知栏 / 提示音** 三种方式任选或全选，并可自定义 `提前 N 分钟`、`每 N 分钟重复`、`共 N 次`；弹窗是与便笺同色的便笺纸（胶带 + 折角），点一下或 30 秒后自动关闭 |
| **提醒铃声可选自己的文件** | 「提示音」可以用 **系统提示音**，也可以**自选一个声音文件**（**wav / mp3 / flac** / wma / m4a / aac…）：编辑窗「提醒」那一行点「铃声…」→ 选择声音文件 / 试听（**在程序里直接播**）/ 停止铃声 / 清除。**mp3 与 flac 都能直接响，不会弹出外部播放器**；提醒弹窗上会写明 `铃声：xxx.flac（这是铃声）`。文件被删掉会自动退回系统提示音。见下节 |
| **便笺墙翻页** | 一页便笺装不下时，页面底部会出现朱红的 **「本页已满 · 新开一页」**：点它就新开一页继续贴（也可以 `PgUp` / `PgDn` 或视图菜单翻页）。一条便笺记着自己在第几页，右键可以「移到上一页 / 下一页」；页码与当前页都会记住，重启还停在那一页。见下节 |
| **复制 / 粘贴便笺** | 便笺墙上的「复制」现在分成两步：**复制便笺**（`Ctrl+C`，工具栏 / 编辑菜单 / 右键菜单）把选中的便笺存进程序内的剪贴板；**粘贴便笺**（`Ctrl+V`）在当前这一页新建一张一模一样的便笺（标题/正文/附件/照片设置都照搬，新 id）。**先点「新开一页」再粘贴，新便笺就落在新页上**；空剪贴板时「粘贴」是灰的。剪贴板只在本次运行内有效（不占系统剪贴板），退出即清空 |
| **表格关键词搜索** | 表格视图右上角有搜索框：输入关键词**边打边筛**（标题 / 正文 / 链接都查，不区分大小写），状态栏显示命中条数；`Esc` 清空、`Ctrl+F` 回到搜索框 |
| **后台运行（不占任务栏）** | 文件菜单「后台运行」把主窗口收进**托盘**：任务栏按钮消失，便笺、提醒弹窗、通知照常工作；左键点托盘图标回到前台，右键菜单里还有「打开全部便笺 / 停止铃声 / 退出」 |
| **CSV 课表导入** | 菜单「文件 → 导入 CSV 课表…」：把教务 / Excel 导出的课表 CSV 直接变成一叠**课表便笺**——自动认出「名称」与「时间」（星期几 + 时刻 / 节次 + 日期），**其余信息（教师、教室、学分、周次…）统一写进正文框**；「一行一节课」的表格型与「行 = 节次、列 = 星期」的网格型都支持，识别结果先弹框确认再导入。见下节 |
| **课表模式** | 把课程（普通日程）标成「课表」，笺会按上下课时间照看便笺：**上课自动贴出**这一节的便笺，**下课时自动关掉它、并把下一节贴在同一位置**（例：数学课下课 → 数学课便笺消失、英语课便笺原地出现）；便笺上显示「距上课 / 距下课」与「下节 课名 时间」。标记入口见下节 |
| **正文逐段文字颜色** | 正文可以像 Word 那样**一段文字一种颜色**（同一段里也能混排）：编辑窗「正文」那一行有 7 枚颜色小方块（黑/红/橙/绿/蓝/紫/灰，第一枚是“默认”= 跟随便笺字色）+「颜色…」自定义取色，先选中文字再点颜色即作用于选区（`Ctrl+A` 后点色＝整篇上色）。**便笺墙与桌面便笺都会逐段还原颜色** |
| **课表便笺的「下一节」名称** | 课表便笺的倒计时下面会多一行「下一节 <课名> <什么时候>」：**点这一行直接打开那节课的编辑窗**（悬停变蓝加下划线、光标变手型）。课名优先显示（放不下时先丢时间不截断课名），字号随便笺大小自适应，且与倒计时一起受保护、不会被挤掉。可在编辑窗「倒计时」那一行或便笺右键里用 **「课表：显示下一节课名称」** 独立开关（老数据默认开） |
| **书签形态** | 便笺可以变成**吸附在屏幕边缘的书签**（左右/上下四条边都能吸）：纸色与便笺一致，书签上竖排/横排显示标题。**鼠标左键拖拽**可以换位置（松手自动吸到最近的边），**左键单击**则还原回原来那张便笺的位置与外观。手动开关（右键菜单 / 编辑窗「便笺…」菜单），状态与还原位置都会记住，重启还在 |
| **倒计时显示精度** | 每条日程可自选倒计时**显示到哪一级**：天 / 时 / 分 / 秒（表格列、卡片、顶部大数字、便笺墙与桌面便笺一并生效），见下节 |
| **开机自启动** | 文件菜单「开机自启动」开关（写入 `HKCU\...\Run`），随时可关 |
| **迁移到桌面** | 「文件 → 数据保存位置 → 迁移：在桌面生成数据拷贝」：一键在**桌面**生成一份带时间戳的文件夹，装着当前全部数据（主数据 / 便笺状态 / 便笺墙 / 历史版本）和一份 `迁移说明.txt`，拷到新电脑把 `笺.exe` 放进去就能直接用 |
| **统一 / 自定义数据位置** | 主数据、便笺状态、便笺墙布局、历史版本**统一放在一个“数据目录”**（菜单「文件 → 数据保存位置」里随时能看到当前路径、改到任意文件夹）；换电脑/换版本/换 exe 位置都不再丢数据。还能**自动找到本机其它位置的旧数据**（桌面、文档、下载、%APPDATA%\Jian、旧 exe 旁边）一键导入，以及把当前数据**备份到任意文件夹** |
| **历史版本存档** | 每次写盘前把**上一次**的数据自动存一份到 exe 同目录的 `zsched_history\`，文件名带时间戳（`zsched_20261015_123732.txt`），至少间隔 2 分钟存一份、最多保留 60 份，超出自动删最旧的；文件菜单里有「存档当前版本」（手动立刻存一份）、「打开历史版本文件夹」（用资源管理器打开）与「恢复最近一个历史版本」（恢复前会先把当前版本也存档，不会丢）|
| 自由编辑 | 双击打开完整编辑窗；`F2` 就地改名；新建 / 复制 / 删除 / 完成 / 暂停 / 改色齐备 |
| 日期 + 时 + 分 + 秒 | 独立日期选择器 + `时:分:秒` 选择器（精确到秒），结束时间可选并自动计算时长 |
| 同框混排不同字号字体 | 正文用 RichEdit 富文本，**同一段文字可混排字体与字号**，支持 **加粗 / 斜体 / 下划线**，另有「整篇应用」。**便笺上也是逐段还原的**：便笺墙与桌面便笺都用自带的富文本渲染器按分段（字体族 / 字号 / 粗体 / 斜体 / 下划线）排版，和编辑窗里看到的一致，不再退化成一种字体大小 |
| 字体按系统字库选择 | 字体下拉枚举**本机全部字体族**（跳过竖排 `@` 字体），字号 8–64pt 可选可键入 |
| 每周循环 | 「每周」可**多选**周一~周日，支持「每 N 周」 |
| 自定义周期循环 | 每 **N 天 / 周 / 个月 / 年**，另有每天 / 每月 / 每年预设 |
| 插入图片等内容 | 每条日程 12 个附件位，图片显示缩略图、其它文件显示类型图标；可增删排序、外部打开 |
| 图片直接显示原图 | 内置**原图查看器**：默认 100% 原始像素、可缩放 / 适应窗口 / 拖拽平移 / 多图切换，角标显示原始尺寸；编辑窗右侧另有预览区 |
| **桌面便笺窗口** | 单条/批量开成独立小窗，可选便笺纸或系统窗口外观，见下节 |
| **纪念日** | 见下节 |
| 最近 / 自选日程倒计时 | 顶部书封色面板：左半屏自动锁定最近一条，右半屏跟随选择或固定某条；大号数字每秒刷新 |

### 笔记本主界面 + 便笺墙（新）

主窗口不再是普通窗体里的控件堆叠，而是**画成一本摊开的笔记本**：

- **外观**：深暖褐封皮 + 书脊暗条、左侧螺旋装订环、纸页投影与下沿纸层、横格线与红色页边线；工具条、倒计时面板、三个视图全部落在纸页内。
- **便笺墙**（清单视图）：每条日程是一张便笺纸，带左上角胶带、右下角折角、随机偏向的柔和投影；按行流式排布，窗口变宽自动多排一列。
- **自由挪动**：按住便笺拖到页面任意位置即“脱队”，松手吸附到 4px 网格并立即写盘；拖到边缘会自动滚动，位置不会跑出页面。
- **固定**：`P` 键或右键「固定在当前位置」，钉住后便笺顶部出现带横杠的灰色图钉，不能拖动也不能缩放（防误操作）；再按一次取消。
- **调整大小**：选中/悬停时右下角出现三条斜线与边条手柄，拖右下角或右/下边缘即可改尺寸；**只保留下限（逻辑 132×104），不设上限**——想铺多大都行，内容（字号、照片、内边距）会跟着一直放大，拖动过程中便笺上实时显示当前尺寸。
- **内容自适应**：字号、行距、内边距随便笺尺寸等比缩放（实测 208×150 与 348×144 下标题/日期/倒计时字号自动变化）；空间不够时按「标题 → 日期 → 倒计时框 → 正文」的优先级逐级省略，长倒计时会自动降一档字号而不是显示省略号。
- **恢复**：右键「恢复自动排列」把便笺放回流式；「恢复默认大小」清掉自定义尺寸；双击右下角手柄同样可恢复默认尺寸；视图菜单另有「便笺全部恢复自动排列 / 全部恢复默认大小」。
- **待办便笺**：无时间的待办在便笺上显示为「☐ 待办（无时间）」，完成后变成「☑ 待办 · 已完成」（用 `空格` 或右键标记完成）。
- **照片便笺**：右键「便笺上直接显示图片」后，便笺上会贴出这张日程的第一张图片附件。照片是一个**独立的小框**：
  - **点选**：**单击照片**才进入编辑（红色虚线框 + 四个角手柄）；鼠标只是经过不会出任何手柄，照片也不会消失；
  - **拖动**：选中后按住照片本身拖到便笺上任意位置（尺寸不变）；
  - **缩放**：拖照片**任意一个角**＝宽高两维同比例缩放（整张照片永远完整、不变形）；右键「照片（可拖动、可缩放）」里有 40% / 55% / 75% / 100% 四挡与「位置与大小复位」；
  - **退出编辑**：**单击便笺别处或按右键**即退出（右键同时弹出便笺菜单；`Esc` 关掉菜单即可）；
  - **不混淆**：只有选中的照片才出手柄，便笺自身的缩放手柄在这种情况下自动隐藏；光标会区分「斜向缩放」与「移动」；
  - **文字优先**：照片框始终会给正文留出至少一行（**照片拖到最大也一样**；正文开头的空行也算，留下的是实际文字行），日期与倒计时框按「照片 → 日期 → 倒计时 → 正文」的次序让位，正文字号在空间不足时自动降一档——不会再出现「照片一大、文字被挤没了」；其余正文用滚轮往下滚就能看到，滚到最底最后一行贴在便笺底边。
  照片的位置与尺寸按便笺内容区的千分比保存，便笺放大缩小时照片跟着等比变化。
- **其它交互**：单击选中（顶部出现纸色图钉）、双击编辑、方向键在网格中移动选择。位置/尺寸/固定/收起状态存在 `zsched_board.txt`。
- **正文颜色**：便笺墙上的正文同样支持逐段颜色（和编辑窗、桌面便笺一致），见「正文逐段文字颜色」。
- **滚轮的三层含义**（按优先级）：① **在便笺内滚动正文**（v1.9 起滚轮不再缩放照片；照片大小用四个角拖）；② 鼠标在这张便笺上且正文超出可视区 → 在便笺内滚动正文（右侧有细滚动条，滚到尽头会自动改为翻页）；③ 其它情况 → 翻动整个便笺列表。独立弹窗便笺与便笺墙卡片都是同一套（v1.9.1 起墙上也不再是 Ctrl+滚轮缩放照片）。

### 桌面便笺独立窗口

- **单条 / 批量**：工具条「便笺」按钮、`Ctrl+B`、右键菜单「打开便笺 / 批量打开便笺」，或菜单「便笺 → 为所有待办开便笺」一次铺开一排便笺。
- **两种外观**（可随时切换）：
  - **便笺纸**：无边框**分层窗口**，带真实柔和投影、程序化纤维纹理、下沿厚度、右下角书页折角，像一张纸贴在桌面上；标题栏不占位。
  - **系统窗口**：标准 `WS_OVERLAPPEDWINDOW`，带系统标题栏、出现在任务栏里。
- **颜色自选**：8 种纸色（鹅黄 / 苔绿 / 樱粉 / 丁香紫 / 天青 / 杏橙 / 素灰 / 黛蓝），参考微软便笺的色泽；便笺上点悬停圆点即可循环换色，或用编辑窗「便笺…」菜单指定。
- **桌面固定**：默认置顶（`HWND_TOPMOST`），点悬停图钉或右键菜单可切换；窗口位置、尺寸、颜色、外观、置顶状态都会持久化到 `zsched_notes.txt`，下次启动自动恢复。
- **交互**：任意处拖拽移动、右下角缩放、双击进编辑窗、右键菜单（编辑 / 设为倒计时目标 / 颜色 / 外观 / 书签形态 / 倒计时精度 / 课表 / 置顶 / 便笺上显示图片 / 图片大小 / 批量 / 关闭）。
- 和便笺墙一样支持**无时间待办**（显示勾选框与「待办（无时间）」）与**直接贴照片**：**单击照片选中**后可拖动位置、拖四个角两维同比例缩放（悬停只变光标、不自动出手柄）；**右键或单击别处退出照片编辑**（右键照旧弹便笺菜单）；右键「照片（可拖动、可缩放）」里有四挡预设与复位；正文同样有「至少一行」的保障。
- 便笺内容：标题、日期与重复规则、倒计时框（纪念日则显示「还有 / 已过去 N 天」）、正文若干行、附件缩略图。
- **窗口标题就是这条日程的标题**：便笺纸外观没有标题栏，但 Alt+Tab 与任务栏列表里能一眼看出这张便笺是哪一节（课表接力时尤其好用）。

### 课表模式

把课程标成课表之后，笺会按上下课时间自动照看便笺：

- **标记**：编辑窗勾「标记为课表：到点自动开关便笺、内容跟随上下课」；列表/表格/便笺墙上右键「课表模式」；桌面便笺右键里也有同样的开关。
- **上课自动贴出**：到上课时间，这一节的便笺自动出现在桌面上（接着上一节的位置；纸色与外观沿用这张日程自己上次的设置）。
- **下课自动接力（v1.7 起为“下课后 5 秒”）**：到下课时间先**不关窗**，等**原课程结束 5 秒后**再把同一个位置上的窗口**整个换成下一节**——
  连堂就换成正在上的下一节；有课间就换成下一节的便笺（显示「距上课 mm:ss」，不等上课）；今天没有下一节就关窗。
  位置会随接力写进 `zsched_notes.txt`。
- **内容自动调整**：课表便笺的倒计时框显示「距上课 …」「距下课 …」，下面再跟一行「下节 英语课 10:00」；这节课下过之后显示「本节已下课」。便笺墙上的课表便笺显示「距上课 / 上课中 / 本节已下课」。
- **没填结束时间**：这一节按 45 分钟计。
- **总开关**：「便笺 → 课表便笺自动跟随」（桌面便笺右键里也有）。关掉后课程照常，只是不再自动开关窗口；手动开的课表便笺不受影响（你关掉的便笺也不会被强行再开出来）。
- 只有**普通日程**（有时间的，且不是待办/纪念日）能标成课表；`timetable=1` 会随数据一起保存。

### 倒计时显示精度

- 每条日程可选**显示到 天 / 时 / 分 / 秒**：天 → `5 天`；时 → `5天 03 时`；分 → `5天 03:24`；秒 → `5天 03:24:41`（默认）。按「还有」的语义，粗档位的最细一级**向上取整**（差 12 分钟 → 「1 时」）。
- 四个入口：编辑窗「倒计时」单选、列表/表格/便笺墙右键子菜单、桌面便笺右键子菜单、视图菜单「倒计时显示精度」（没有选中任何日程时就作用于**全部**日程）。
- 生效位置：表格的倒计时列、清单卡片的倒计时框、顶部大号数字、便笺墙与桌面便笺的倒计时框。课表便笺默认看到「分」，可在编辑窗改成「秒」。

### 纪念日

用于记录**已经过去的事**（入职、相识、搬家…）：

- 编辑窗勾选「纪念日（记录已过去的事）」即可。
- 便笺的倒计时框换成 **「已过去 1244 天」**；表格里倒计时列显示「已过去 N 天」，标题带 ◇ 前缀。
- 桌面便笺与倒计时面板上显示 `已过去 1244 天（3 年 4 个月）`，按日历差计算，自动处理大小月与闰年。
- 配合「每年」重复，周表格里每年纪念日当天都会出现带 ◇ 的条目。
- 纪念日不参与「已完成」归档，始终显示为仍在记录的状态。

### 正文逐段文字颜色（参考 Word）

- **怎么上色**：编辑窗「正文」行的字体/字号原本就有 B / I / U 与「整篇应用」，紧挨着右边新增 **7 枚颜色小方块**
  （① 默认＝自动色，跟随便笺本身的字色；② 红 ③ 橙 ④ 绿 ⑤ 蓝 ⑥ 紫 ⑦ 灰）和一枚 **「颜色…」**（系统取色盘，可选任意颜色）。
  - **选中哪段就染哪段**：颜色只作用于**当前选区**（没选区时作用于插入点，之后打的字就是那个颜色）——和 Word 一样；
    要整篇一个颜色就先 `Ctrl+A` 再点颜色（「整篇应用」按钮只管字体/字号/B/I/U，不动颜色）。
  - 光标移到某段文字上时，对应的小方块会自动加一圈高亮框，一眼能看出这段是什么颜色。
- **便笺上原样显示**：便笺墙（清单视图）与桌面便笺都用自己的富文本渲染器逐段取色（解析 RTF 的 `\colortbl` + `\cfN`），
  所以一张便笺上可以同时有红、蓝、绿……和编辑窗里看到的一模一样；倒计时框、日期、标题仍用便笺自己的颜色。
- 颜色是存在日程的 RTF 正文里的，跟着数据文件走，和字体/字号一样会持久化。

### 课表便笺的「下一节」名称行

把课程标成课表后，便笺的倒计时框里会多一行提示下一节课：

- **内容**：`下一节 英语精读与写作 22:51` —— 课名 + 什么时候（今天只显示 时:分，明天/后天会写明，更远的带星期）。
- **可点击**：鼠标移到这一行会**变蓝加下划线、光标变手型**，单击即打开**那节课**的编辑窗（便笺自己的编辑窗仍走双击/右键）。
- **独立开关**：编辑窗「倒计时」那一行新增「课表：显示下一节课名称」，便笺右键菜单里也有同一个开关（只有勾了“课表”才可点）；
  老数据默认按“开”算。
- **显示优先级**：课名最重要——放不下先自动降档字号，再放不下就先丢掉“什么时候”，绝不把课名截断；
  「下一节」这一行与倒计时一起算进框高，空间再紧也会先降倒计时字号、再让掉日期行，不会把这两行吞掉，也不会挤占正文（正文按原有优先级拿剩余空间）。
- 便笺放大缩小时这一行的字号跟着自适应；内容每秒刷新（倒计时是活的）。

### 书签形态（吸附屏幕边缘）

把一张桌面便笺变成“书签”，它会像贴在屏幕边上的一根纸带：

- **开启**：便笺上点右键 →「书签形态（吸附屏幕边缘）」，或编辑窗底部「便笺…」菜单里也有同样一项（手动开关，不自动）。
- **吸在哪条边**：开启时按便笺当前离哪条边最近来吸（左/右/上/下四条边都支持，多显示器时吸在它所在的那块屏上）。
  竖着吸（左/右边）时标题竖排，横着吸（上/下边）时标题横排。
- **颜色**：书签纸色 = 这张便笺的便笺纸颜色（点便笺上第一颗悬停圆点换色时，书签也跟着变）。
- **拖拽**：鼠标左键按住书签拖动即可换位置，松手自动吸到离得最近的边。
- **单击还原**：**不拖动**、只左键单击一下，书签就还原成普通便笺，回到它变成书签之前的位置与外观（系统窗口/便笺纸都记得）。
- **持久化**：吸在哪条边、还原回去的位置都存在 `zsched_notes.txt` 里（`style=2 edge=… rx/ry/rw/rh`），重启后仍是书签。
- 书签上不显示悬停按钮与缩放手柄：它的交互就三件事——拖动、单击还原、右键菜单。

### 数据保存位置（统一目录 + 自定义路径 + 导入旧数据）

以前四份东西（`zsched_data.txt` / `zsched_notes.txt` / `zsched_board.txt` / `zsched_history\`）都跟着 exe 走，
把 exe 挪个地方或换个版本，数据就“看不见”了。现在它们**统一跟着一个“数据目录”**：

- **默认**：exe 所在目录（和以前一样，老数据不用动）。
- **改到别处**：菜单「文件 → 数据保存位置 → 选择数据文件夹…」，选任意文件夹即可（设置存在 `HKCU\Software\Jian\DataDir`，
  所以**桌面那份和工程目录那份 exe 会共用同一份数据**，不会再各写各的）。
  - 目标文件夹是空的 → 问你要不要把当前数据**复制过去**（推荐）还是只切换位置；
  - 目标文件夹里已经有一份数据 → 问你要不要**改用那份**（当前这份会先自动存档，不会丢）。
- **导入旧数据**：菜单「文件 → 数据保存位置 → 迁移 / 导入已有数据…」，会自动扫这几处并按最后修改时间列表：
  exe 目录、当前数据目录、`%USERPROFILE%\Desktop`、`Documents`、`Downloads`、`OneDrive\Desktop|Documents`、`%APPDATA%\Jian`、`%LOCALAPPDATA%\Jian`。
  列表里能看到每份的「日程条数 · 便笺条数 · 最后修改时间 · 路径」，选一份点「改用这一份」即可（**只切换，不复制、不删除**，两边文件都留着）。
- **迁移（v1.8）**：菜单「文件 → 数据保存位置 → 迁移：在桌面生成数据拷贝」——点一下就在**桌面**建一个带时间戳的文件夹
  `笺数据迁移_20261017_165716`，里面是主数据 / 便笺状态 / 便笺墙 / 历史版本的完整拷贝，另附一份 `迁移说明.txt`，
  复制完自动打开该文件夹。同一秒连点两次会自动加 `_2` / `_3`，不会互相覆盖。
- **备份 / 导出**：菜单「文件 → 数据保存位置 → 备份当前数据到文件夹…」，把四份东西整份复制到你选的文件夹（迁移到新电脑时用这个）。
- **打开数据文件夹**：一键在资源管理器里打开当前数据目录。
- 切换数据位置时是**热切换**：不用重启，便笺与便笺墙会按新目录里的状态重新恢复。
- 老格式的数据文件（v1 及更早）载入时会自动升级回写，旧便笺状态文件里陌生/缺失的字段都会被安全忽略，所以**旧版本的便笺数据能直接读**。

### 提醒铃声：系统提示音 / 自选声音文件

- **在哪设置**：编辑窗「提醒」那一行最右边点 **「铃声…」**（勾了「提示音」才可点），按钮右边实时显示当前用的是哪种铃声。
- **两种来源**：
  - `系统提示音（Windows 默认）` —— 就是以前那声系统提示音；
  - `自选声音文件` —— 用「选择声音文件…」挑一个音频文件（wav / mp3 / wma / m4a / aac / ogg / flac / mid 都能选），
    也可以随时「试听（在本程序里播放）」「停止铃声」或「清除自选文件」。
- **到点怎么响**：程序内直接用 **Media Foundation** 解码播放（wav / mp3 / flac / wma / m4a…），
  **不会拉起外部播放器**；MF 不可用时退回 MCI（老系统 wav/mp3），再不行才交给系统默认程序。
  文件不在了会**自动退回系统提示音**。
- **只勾了「提示音」时**：没有便笺弹窗可点，所以响铃时会出现一个**小窗**（右下角、纸色跟日程一致），
  带一个真正的 **「停止铃声」** 按钮——点按钮或点窗口立即停铃；**声音放完小窗会自己关掉**。
  勾了「便笺弹窗」的提醒不弹小窗（点弹窗就是停铃）。
- **怎么知道响的就是铃声**：提醒弹窗（便笺纸那张）在时间下面多一行 **`铃声：ring.flac（这是铃声）`**，
  窗口会相应加高一点；通知栏气泡照旧显示日程标题与时间。
- 选完铃声会**自动把「提示音」勾上**（不然选了也不会响）；铃声设置随这条日程一起保存/存档/进历史版本。

### 便笺墙翻页

- **页码栏**在便笺墙底部居中：`‹ 第 1 / 3 页 ›` + `＋ 新一页`。
- **本页满了**：这一页的便笺装不下时，那个按钮会变成朱红实心的 **「本页已满 · 新开一页」**——
  点一下就在后面新开一页并翻过去。也可以 `PgUp` / `PgDn`，或用视图菜单「上一页 / 下一页 / 新开一页」。
- **便笺属于哪一页**：在某一页新建的便笺就记在这一页；右键便笺有「这张便笺在第 N 页 / 移到上一页 / 移到下一页」。
- **会记住**：当前页数、总页数、每张便笺的页码都写进 `zsched_board.txt`（`viewpage=` / `pages=` / `page=`），
  重启后还停在那一页，空页也不会丢。
- **便笺窗口数量不设上限**了（以前最多 64 个、启动最多恢复 24 个）：实测 80 张便笺可以全部打开、全部恢复。

### 表格关键词搜索

- 切到**表格视图**，右上角就是搜索框（提示「搜索：标题 / 正文 / 链接（Esc 清空）」）。
- 输入即筛选（不区分大小写的子串匹配），状态栏右侧显示「搜索「关键词」：N 条」。
- `Esc` 清空并恢复全部；`Ctrl+F` 无论在哪都会切到表格视图并聚焦搜索框。
- 搜索只作用于表格视图；清单 / 周表不受影响（切回表格时关键词还在）。

### 后台运行（托盘）

- 文件菜单 **「后台运行（不占任务栏）」**：主窗口收进托盘，**任务栏按钮消失**，
  桌面便笺、提醒弹窗、通知栏照常工作（实测后台状态下提醒弹窗照常弹出）。
- **托盘图标**一直在：左键单击 = 显示 / 收起主窗口；右键菜单 = 显示主窗口 / 后台运行 / 打开全部便笺 / 停止铃声 / 退出。
- 第一次进入后台会弹一条气泡提示。

### CSV 课表导入

菜单 **「文件 → 导入 CSV 课表…」**，选一个 CSV/TXT 课表文件，确认识别结果后即可导入。支持两种常见格式：

- **表格型**（一行一节课）：表头里有「课程名称 / 上课时间 / 星期 / 节次 / 日期」等列即可；
  列名不认识时按每列内容自动推断哪一列是课程名、哪一列是时间。
- **网格型**（学期课表）：第一行是星期（`星期一…` 或 `1 2 3…`），第一列是节次（`第1节` 或 `1`），
  格子里填课程名；一个格子里写了多门课（用空行分隔）也会拆成多条，格子里除课名以外的行（教师、教室）进正文。

**识别规则（正则匹配）**：

| 认什么 | 认出来的写法（举例） | 变成什么 |
| --- | --- | --- |
| 名称 | 表头「课程名称 / 科目 / 课名 / name / subject…」那一列（或按内容推断最像课程名的一列） | 便笺**标题** |
| 星期 | `周一` `星期三` `礼拜日` `周3` `mon`…（多个也行：`周一、周三`） | 重复 = **每周** + 对应星期几 |
| 时刻 | `8:00` `08:00` `8.00` `8点30` `14：00`（全角也行）；成对出现即开始+结束 | 便笺**开始 / 结束时间** |
| 节次 | `第3-4节` `1、2节` `第5节` | 按**内置作息表**推时间（第 1 节 08:00、第 2 节 08:55 …每节 45 分钟），正文里会注明“按内置作息表推导” |
| 日期 | `2026-11-20` `2026年11月20日` | 那一天开始（没有星期就当作一次性日程） |
| 其余列 | 教师 / 教室 / 学分 / 周次 / 备注 / 序号… | **一律按「列名：值」写进正文**（序号这种纯数字列自动丢掉） |

**其它细节**：

- 编码自动识别：**UTF-8（含 BOM）/ UTF-16LE / GBK** 都能读；分隔符在 `,` `;` `Tab` `|` 里自动挑；
  引号包裹、`""` 转义、**引号里的换行**（Excel 导出的多行单元格）都能正确读。
- 导入确认框会列出：格式 / 表头在第几行 / 分隔符 / 名称列 / 时间列 / 其余几列写入正文，外加逐条预览
  （`1. 高等数学 周一 8:00-9:40 · 正文 3 行`），确认无误再点导入。
- 两个入口：**「导入并打开便笺」**（顺手切到清单视图并把便笺贴出来，一次最多 16 张）
  与 **「仅导入到清单」**（只建日程，不弹窗）。
- 导入出来的都是**课表便笺**（`timetable=1`，到点自动开关便笺），倒计时默认显示到「分」；
  同名 + 同星期 + 同时间的行会自动跳过，重复导入同一份课表不会翻倍。

### 关于图片格式

- 常规格式（PNG / JPEG / BMP / GIF / TIFF / ICO）走 **GDI+** 解码。
- WebP、HEIC、AVIF 等只要系统注册了解码器就自动回退到 **WIC（Windows 成像组件）**。
  提示「图片无法读取」通常意味着本机没有该格式的解码器（例如未安装商店里的「Webp 图像扩展」）。

- 桌面便笺：同一数据目录下的 `zsched_notes.txt`（记录每条便笺的位置/尺寸/颜色/外观/置顶）。

- 桌面便笺状态文件 `zsched_notes.txt` 的首行是 `ttauto=1/0`（课表便笺自动跟随开关）。
- 任何改动立即写盘；命令行可指定数据文件：`笺.exe D:\我的日程.txt`。

### 几个实现要点

- **便笺的真实投影**：便笺用 `WS_EX_LAYERED` + 逐像素 alpha（`UpdateLayeredWindow`）。做法是先把纸面、纹理、折角、文字全部画进 32bpp DIB（GDI 只写 RGB），最后按**几何**逐像素重算 alpha：圆角矩形内部 255、外圈按到边界的距离渐隐——因此阴影不依赖任何位图资源，也不会把文字边缘弄脏。
- **纸质纹理**：启动时用确定性伪随机数生成 96×96 的瓦片位图（底色 + 噪点 + 几笔深色纤维短划），再 `CreatePatternBrush` 缓存成按底色索引的画刷；填充时用 `SetBrushOrgEx` 把纹理对齐屏幕，多张卡片看起来像同一种纸。
- **布局全部由字体度量推导**：按钮宽度量文字、行高取 `GetTextMetrics`，编辑窗整体按 DPI 等比缩放并带屏幕高度上限保护，100%/150%/200% 下都不会裁字。
- **周期推算**用「自然日序号」做日期运算绕开时区/夏令时；求下次发生用除法直接跳到目标周期再回退校验，不会因年代久远而线性循环。同一套规则另有「某一天是否发生」的判定供周表格展开。
- **RTF→纯文本**：自己写的极简解析器，跳过 `\fonttbl`/`\colortbl`/`\*` 等目标组、处理 `\'hh` 与 `\uNNNN?` 转义、把 `\par` 变换行。注意 `\uc1`、`\uc0` 是**控制字**不是 Unicode 转义——只有 `u` 后面紧跟数字或负号才算转义。
- **便笺的内容自适应**：字号按「DPI 百分比 × 尺寸系数」量化到 4% 一档后缓存（每档 5 个 HFONT + 行高），便笺缩放时只是换一套字体，不重建窗口；文字先量宽再决定是否省略（例如日期行放不下「每天」就去掉它而不是打省略号）。
- **便笺墙的缩放/命中**：位置与尺寸都存**逻辑像素**（存盘后换 DPI 也对），内部用「行式流布局」缓存每张便笺的矩形；被拖出流式的便笺不再占位，其余便笺自动回流。命中测试与绘制用同一套矩形，夹紧在可视区内。
- **便笺上的富文本渲染**：`richtext.c` 里新增了一个小型 RTF 分段解析器（按 `{}` 分组保存/恢复字符格式，处理 `\fN` 字体表、`\fsN` 半磅字号、`\b \i \ul` 字形、`\'hh` ANSI 字节与 `\uNNNN`），再逐段选字体折行绘制：字体按「族 + 半磅 + 字形 + 便笺缩放」缓存 HFONT，折行用「先量整段、放不下就二分找最长前缀」的稳妥做法（`GetTextExtentExPointW` 的逐字符累计宽度在 CJK 上不可靠），并且同一套函数既用于绘制也用于量高度，滚动范围因此始终准确。
- **GDI+ / WIC 手工对接**：`IWICFormatConverter::Initialize` 在虚表索引 8，目标格式 `GUID_WICPixelFormat32bppPBGRA` 末位是 `0x10`，WebP 必须走「读入内存 → 从流解码」（按文件名解码找不到解码器）。
- **自带极简正则引擎**（`csvimport.c`）：MinGW-w64/w64devkit 不带 `<regex.h>`，而“认表头、认星期/时刻/节次”用正则最稳，
  于是写了一个够用的子集：编译成结点树，再用**续接（continuation）**方式匹配——`m_chain(结点链, 续接)` 里把“后面还要匹配什么”
  显式传下去，所以组 / 分支 / 量词的失败都能正确回退（`(a|ab)c` 命中 `abc`）；组捕获的终点靠一个专门的“组结束”续接帧记录（走到那儿就是组的结尾）。
- **自选铃声不做音频解码**：提醒到点用 `ShellExecuteW(L"open", 文件)` 交给系统默认程序（所以 mp3/m4a/flac 都能响），
  并在提醒弹窗上写明「（这是铃声）」——既省掉解码器，也让“为什么冒出一个播放器”一目了然。

## 五、已知边界

- 附件只保存**文件路径**，不复制文件；源文件被移动/删除后缩略图空缺并提示。
- 便笺窗口**不设上限**（v1.6 起）；便笺墙按页存放，一页满了可以「新开一页」。
- 正文纯文本上限 4000 字、RTF 上限 16000 字；数据文件单次读入上限 64 MB；每条日程附件上限 12 个。
- 系统未安装对应解码器时，该图片格式无法预览，但可用「外部打开」。

### 数据文件与历史版本

- 数据目录下的 `zsched_history\` 保存历史版本（自动 + 手动），可用文件菜单打开或恢复；导入/切换数据位置前也会先存一份。

### 修掉的问题

- **备份 / 迁移出来的 `zsched_history` 一直是空目录**（v1.8）：复制历史快照时源路径拼成了“数据目录 + 文件名”，
  漏掉 `zsched_history\` 这一层，于是每次都找不到文件、静默跳过。现在拷贝里会带上全部历史快照。
- **清单里便笺多时，收起一张会留下残影**：绘制用的是“这一页要画的顺序表”，但循环上限取的是便笺总数，
  收起便笺后顺序表变短，多出来的几趟会读到上一轮的残留下标，把已经收起的便笺按旧位置又画一遍。
  现在只走有效项，并在绘制前再判一次是否已收起。
- **课表便笺不显示倒计时**：以前“今天这节课不在进行中”就只写「本节已下课」/「课表 · 今天没这节」，没有倒计时。
  现在这两种情况都回退到普通倒计时（「下节课 …」/「还有 …」），便笺墙上的课表便笺同样处理。
- **便笺上的倒计时不会自己走**：主循环每秒只刷新了顶部面板与三个视图，没重绘便笺窗口，所以便笺上的倒计时/「下一节」名称会停在打开那一刻 → 现在每秒重绘一次便笺。
- **提醒的「提前 / 重复间隔 / 共 N 次」改完确定后不生效**：编辑窗读这三个数字框时误用了“写控件”的函数
  （`ctl_text` 内部是 `SetWindowText`），等于用未初始化的缓冲覆盖控件再解析它——用户输入的值每次都被丢掉。
  改用真正的读取函数。另外“提醒方式 / 提前 / 间隔 / 次数”任何一项改变都会让提醒**重新计时**，改完立刻按新设置生效。

- **清单界面「收起」之后摆不回来，而且明明还有便笺也提示「便笺都收起来了」**（三处独立缺陷）：
  1. 视图菜单里的便笺项只接了右键菜单那一份，**主菜单里点了没反应**；现在两处都接通，并在视图菜单补上「收起选中的便笺（H）」。
  2. 菜单项的可用状态/文案是**启动时算一次**、之后不刷新（「显示所有便笺」永远灰着）；刷新消息里把菜单句柄取成了 `lParam`
     （`WM_INITMENUPOPUP` 其实在 **`wParam`**），所以连「当前数据位置」标签也一直没刷新过——一并修正，现在每次打开菜单都会按当前状态刷新。
  3. 「都收起来了」的判定用了**全局**收起数，把已删除日程留下的旧记录也算进去，于是页面上还有便笺也照样提示、菜单状态也被带偏；
     现在只统计「当前这一页里、日程仍存在」的便笺，并在存盘时顺手清掉那些已经没用的残留记录。

- **表格里“还没到的倒数日”显示成「已过去 0 天」**：倒数日文案一直写死「已过去 N 天」，日期还没到时按日历差算出来正好是 0，于是显示成「已过去 0 天」。现在统一按 **「还有 N 天」/「已过去 N 天」/「就是今天」** 三种情况显示（表格列、清单卡片、顶部倒计时面板走同一套文案），并且重复的倒数日不会再出现「还有 N 天（距下次 299 天）」这种自相矛盾的叠加。

- **便笺上字体不生效（只有编辑窗里看得出）**：RichEdit 对非 ASCII 字体名会写成 ANSI 转义（如 `\'bb\'aa\'ce\'c4\'bf\'ac\'cc\'e5` = 华文楷体），而字体表解析里“跳过 `\fnil\fcharset134`”的那段循环把这些转义也一起吃掉，字体名成了空的 → 建字体失败、回落默认字体。现在字体表里的名字会正确做 ANSI 解码（实测：华文楷体 / 华文中宋 + 16pt 都能正确还原），便笺上与编辑窗里显示一致。
- **桌面便笺里照片与文字区域错乱**：画了大图之后没有置 `drewBig`，底部那排小缩略图仍在画并压住正文；同时日期/倒计时被“优先让位给正文”的规则丢掉。现在画了大图就不再画小缩略图，并按「日期 → 倒计时 → 正文」的优先级分配剩余高度（每一项都要求至少留出行位置）。

- **桌面便笺双击进不了编辑窗**：便笺窗口是没有父窗口的（这样系统窗口外观才会出现在任务栏），而便笺上的双击/右键命令都往 `GetParent()` 发消息——等于发给了桌面。现在便笺模块记住了主窗口句柄，双击、右键里的「编辑」「设为倒计时目标」「批量打开」「关闭全部」都能正确落到主窗口。
- **照片被当成便笺缩放**：原先照片只有一个「拖下沿」的隐性热区，很容易和便笺右下角的缩放手柄混淆，笔记本里的便笺更是几乎点不中。现在照片有独立的虚线框与八个手柄，命中优先级高于便笺本身。

- **便笺纸形态拖不动**：拖动时只更新了窗口左上角、没有同步右下角，等于一边拖一边把纸压扁，看起来就是「拖不走」。现在拖动保持尺寸不变（系统窗口形态有标题栏可拖，所以之前只在便笺纸上暴露出来）。
- **富文本摘要被截断**：`rtf_to_plain` 里累积 `\'hh` ANSI 字节的缓冲只有 4 字节，一串中文超过两个字后面的字节就被丢掉（「每月 1 号，转账后截图存到云盘。」只剩「每月 1 号，」）。缓冲已放大到 1KB 并在将满时先落盘解码，长中文富文本摘要现在完整。
